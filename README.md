# השור הזועם 🐂

משחק לטלפון: שור בזירה נוגח בכדורים האדומים ומתחמק מכל השאר.
50 שלבים, בוסים, חנות, כוכבים וטבלת אלופים, ב-30 שפות.

## לשחק
**https://itzikc4115634-pixel.github.io/angry-bull/**

## להתקין בטלפון (בחינם)
- **אנדרואיד (Chrome):** פותחים את הכתובת ← תפריט ⋮ ← "התקנת אפליקציה" או "הוספה למסך הבית".
- **אייפון (Safari):** פותחים את הכתובת ← כפתור השיתוף ← "הוסף למסך הבית".

אחרי ההתקנה המשחק נפתח במסך מלא, עובד גם בלי אינטרנט, ומתעדכן לבד כשיש גרסה חדשה.

## מה יש כאן
- `index.html` – כל המשחק, בקובץ אחד
- `sw.js` – שומר את המשחק בטלפון, כדי שייפתח מהר ויעבוד בלי אינטרנט
- `manifest.webmanifest` ו-`icons/` – השם והסמל של האפליקציה
